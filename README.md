# Послевкусие — дневник атмосферы дня

**ArtTech · Genesis Hackathon 2026 · кейс «Make the Invisible Visible»**

Личный дневник, который превращает один день — текст, фото и песню — в живую страницу-воспоминание 9:16 с музыкой.
У каждой страницы свой художественный приём, палитра из ваших фото, ритм из темпа песни и название-папка.

## Как проверить

**Онлайн:** https://poslevkusie-phi.vercel.app При первом открытии автоматически собирается демо-дневник из 6 дней.

**Локально** (нужен любой статический сервер, сборка не требуется):

```bash
cd poslevkusie
python -m http.server 5173
# или: npx serve .
```

Откройте http://localhost:5173 в Chrome или Edge (последние версии).

### Сценарий проверки за 2 минуты
1. «Дневник» — 6 дней с разным настроением и шестью приёмами.
2. Любой день → «▶ Смотреть»: страница оживает под музыку, кадры меняются в такт.
3. «Озвучить запись» — голос под настроение дня.
4. Блок «почему он выглядит так» — правила «вход → решение».
5. «Записать день»: слова → фото → песня → «Проявить день» → 3D-проявка.
6. «Система» — схема и карта настроений с ползунками.
7. «Видео с музыкой» и «Папка дня .zip».

## Что реализовано
- Ввод: свободный текст, 1–8 фото (drag & drop), песня — аудиофайлом или ссылкой (YouTube, Spotify, Яндекс Музыка, SoundCloud, Apple Music) с описанием.
- **Анализ текста**: собственный русский лексикон (~300 основ) → приятность, энергия, напряжение, тепло, люди рядом, ностальгия; места, время суток, сезон, погода, детали; учёт отрицаний и усилителей.
- **Анализ фото**: k-means палитра, свет, контраст, насыщенность, теплота, цветистость.
- **Аудиоанализ в браузере**: BPM (spectral flux + автокорреляция), энергия, мажор/минор и тональность (хромаграмма + Крумхансл–Шмуклер), яркость (спектральный центроид), плотность, огибающая.
- **Музыка по ссылке**: словарь жанров и ~70 исполнителей, год → эпоха; встроенный плеер сервиса.
- **Визуальная система**: вектор настроения → 1 из 6 приёмов (Моне, Матисс, Кандинский, «ма», плёнка, коллаж) + палитра, ритм, переходы, воздух, зерно, частицы погоды, типографика, голос.
- **Объяснимость**: блок «Почему этот день выглядит так» на каждой странице и файл `почему_так.txt` в папке дня.
- **Название дня** 3–7 слов в едином тоне («Ночь в офисе перед сдачей», «Зимняя деревня и пироги»); можно переименовать.
- **Воспоминание**: анимированная страница 9:16 под музыку; экспорт в видео .webm со звуком (MediaRecorder), обложка .png.
- **Проявка дня** (`js/confirm3d.js`, Three.js + GSAP): кинематографичная сцена после сохранения. Проценты не обгоняют реальный конвейер; темп сцены зависит от энергии дня; слои за отпечатком — палитра дня. Учитывает `prefers-reduced-motion` (без 3D), работает на телефоне, освобождает WebGL-ресурсы после закрытия.
- **Папка дня** (.zip) с именем «дата — название».
- **Озвучка**: Web Speech API, голос/скорость/высота по правилам настроения.
- **Архив**: лента обложек, поиск по тексту/названию/песне, фильтр по настроению, листание «предыдущий/следующий день».
- **Демо-дневник**: 6 дней с процедурными «фото» и синтезированной музыкой — без чужих снимков и песен.
- Всё работает в браузере: без сервера, без ключей, данные в IndexedDB.

## Дизайн
Сайт оформлен как «проявочная комната памяти»: тёмная среда, единственный красный акцент (цвет фотофонаря), дни «проявляются» в 3D-сцене (Three.js), анимации на GSAP ScrollTrigger, плавная прокрутка Lenis, шрифты Unbounded + Onest + JetBrains Mono. Полное описание системы — в `DESIGN.md`.

## Ограничения (честно)
- По ссылке на сервис звук недоступен для анализа (CORS/лицензии) — используется описание песни. YouTube, Spotify и SoundCloud запускаются вместе с воспоминанием; Яндекс Музыку и Apple Music нужно включить кнопкой в их плеере. Если владелец видео запретил встраивание, сайт объясняет это и предлагает заменить песню файлом. Звук по ссылке не попадает в экспортируемое видео.
- Озвучка через синтез браузера: её нельзя записать в файл, в папку дня кладётся профиль голоса и текст. Набор голосов зависит от ОС (на Windows есть Irina/Pavel).
- Видео экспортируется в реальном времени (15–45 с) и в формате WebM.
- Данные хранятся в браузере: другой браузер или устройство — другой дневник.
- Песню целиком не храним: от аудиофайла остаётся фрагмент до 45 с (тот, что звучит в воспоминании), моно WAV. Он же кладётся в папку дня.
- Определение лада по синтетическим демо-трекам иногда ошибается; на реальных песнях точнее.
