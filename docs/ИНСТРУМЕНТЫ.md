# Использованные инструменты

**Собственный код команды** (весь анализ и рендер написаны с нуля, без ML-моделей и внешних API):
лексикон и разбор русского текста, k-means палитра, БПФ и аудиоанализ (BPM, лад, центроид), визуальная система и правила, генератор названий, рендер 6 художественных приёмов на Canvas 2D, процедурные демо-сцены и синтез демо-музыки.

**Веб-платформа (встроено в браузер):**
- Canvas 2D: рендер страниц, обработка пикселей
- Web Audio API: декодирование и анализ звука, воспроизведение, OfflineAudioContext для синтеза демо-музыки
- MediaRecorder + captureStream: экспорт видео со звуком
- Web Speech API (speechSynthesis): озвучка
- IndexedDB: хранение дневника

**Библиотеки и ресурсы** (лежат в папке `vendor`, сайт не зависит от внешних CDN):
- JSZip 3.10.1 (MIT): сборка папки дня в .zip
- Three.js 0.160 (MIT): 3D-сцена главного экрана и «проявка дня» после сохранения
- GSAP 3.12.5 + ScrollTrigger: анимации по скроллу и таймлайн «проявки дня»
- Lenis 1.1.13 (MIT): плавная прокрутка
- Шрифты Google Fonts (OFL): Unbounded, Onest, JetBrains Mono — интерфейс; Cormorant Garamond, Caveat — страницы дней
- Профили тональностей Krumhansl–Kessler (научная публикация, 1982)
- Метрика цветистости Hasler & Süsstrunk (2003)

**Встраиваемые плееры:** YouTube IFrame API, Spotify Embed iFrame API, SoundCloud Widget API (управляются вместе с воспоминанием); Яндекс Музыка и Apple Music (официальные iframe-плееры).

**AI-инструменты:** Claude (Anthropic) использовался как ассистент при написании кода и документации. В самом продукте генеративные модели не используются.

**Хостинг:** Vercel (статический сайт).
